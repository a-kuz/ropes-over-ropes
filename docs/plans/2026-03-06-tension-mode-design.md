# Tension Mode — Design Document

## Overview

Новый игровой режим внутри iOS-приложения Strain. Игрок использует натяжение резинок для перемещения грузов в целевые зоны на доске. Физика работает в реалтайме — перецепил резинку, груз сразу реагирует.

## Core Loop

1. На доске: дырки, резинки, грузы, целевые зоны
2. Игрок перецепляет концы резинок между дырками и грузами
3. Натяжение резинок двигает грузы в реалтайме
4. Все грузы в целевых зонах → уровень пройден

## Новый объект: Груз (Weight)

### Свойства
- Позиция на поверхности доски (x, y), z = 0
- Масса (определяет инерцию и порог сдвига)
- Радиус (для визуала и коллизий)
- Скорость (для интеграции движения)
- Список прицепленных резинок (концы, привязанные к грузу)

### Физика
- Каждый кадр: суммируем силы натяжения всех прицепленных резинок
- Сила натяжения одной резинки: `F = direction * max(0, currentLength - restLength) * stiffness`
- Статическое трение: груз не двигается пока `|F_total| < μ_static * mass * g`
- Кинетическое трение: `F_friction = μ_kinetic * mass * g * (-normalize(velocity))`
- Интеграция: Verlet или простой Euler (как проще встроить в существующий цикл)
- Демпфирование скорости для предотвращения бесконечного скольжения

### Параметры (начальные значения, подбираются при тестировании)
- mass: 2.0
- radius: 0.3
- μ_static: 0.4
- μ_kinetic: 0.25
- stiffness: 5.0
- damping: 0.95

## Целевая зона (Target Zone)

- Позиция (x, y) и радиус на поверхности доски
- Визуал: подсвеченное кольцо (glow), цвет соответствует грузу
- Условие зачёта: центр груза внутри зоны И скорость груза < threshold
- Когда груз "встал" в зону — тактильный отклик (haptic) + визуальный feedback

## Взаимодействие игрока

Тот же жест что и в основном режиме:
- Тап на конец резинки → начало драга
- Тащим к дырке ИЛИ к грузу → snap
- Груз — это "подвижная дырка": конец привязывается к центру груза
- При движении груза привязанные концы двигаются вместе с ним

## Win Condition

- Все грузы находятся в своих целевых зонах
- Скорость всех грузов < epsilon (settled)
- Victory overlay (как в текущем режиме)

## Уровни

### Формат LevelDefinition (расширение)
```
mode: "untangle" | "tension"     // новое поле, default = "untangle"
weights: [{                       // только для tension mode
  position: [x, y],
  mass: Float,
  radius: Float
}]
targets: [{                       // целевые зоны
  position: [x, y],
  radius: Float,
  weightIndex: Int               // какой груз сюда нужно доставить
}]
```

### Генерация уровней (v1 — ручные)
Первые 5-10 уровней создать вручную для правильного game feel. Процедурная генерация — позже.

## Визуал

### Груз
- Металлическая шайба/цилиндр на поверхности доски
- Отбрасывает тень (существующий shadow pass)
- Instanced rendering (как holes)

### Целевая зона
- Кольцо на доске с мягким glow
- Цвет соответствует грузу
- При зачёте — яркая вспышка

### Резинки к грузу
- Визуально идентичны обычным — конец "входит" в груз как в дырку

## Архитектура реализации

### VerletSimulator
- Новый массив `weights: [Weight]`
- В `update()`: после constraint solving — обновление позиций грузов
- Pins привязанные к грузам двигаются вместе с грузом

### Renderer
- Новый mesh: WeightMeshBuilder (цилиндр)
- Новый mesh: TargetZoneMeshBuilder (кольцо на доске)
- В HDR pass: рендер грузов и зон
- Шейдеры: weightVertex/weightFragment, targetFragment

### LevelDefinition
- Добавить поля: mode, weights, targets
- Обратная совместимость: если mode отсутствует → "untangle"

### ContentView
- Переключатель режимов (tab или отдельный экран)
- Отдельная прогрессия уровней для tension mode

## Что НЕ входит в v1
- Колёса, шурупы, вентили (будущие объекты)
- Разрывающиеся резинки
- Ямы с грузами
- Процедурная генерация tension-уровней
- Android/web порт tension mode
