# Rescue Mode — промпт для нового сеанса

## Цель

Новый игровой режим "Rescue" для Strain (physics puzzle, Verlet rope simulation).

Платформа висит на 3-4 трубках. Одна оторвалась. Игрок ловит свободный конец, тянет к слоту на платформе, вставляет. Платформа стабилизируется → победа.

---

## Негативный опыт (проверено, не работает)

### 1. Отдельная физическая система для платформы
Сделал `updatePlatforms()` — свой Verlet, свои constraints, отдельно от верёвок. Платформа и верёвки жили в параллельных вселенных. Никакого взаимного влияния. Платформа стояла на месте, верёвки растягивались в бесконечность.

### 2. Pin system для связи верёвка↔платформа
`pinEnd = -1000` → rope end телепортируется к углу платформы каждый кадр. Одностороннее: верёвка следует за платформой, но платформа не чувствует верёвку. Итог тот же — нет физической связи.

### 3. "Mutual constraint" костыль поверх пинов
Пытался компенсировать однобокость пинов через `mix(cornerPos, particlePos, 0.3/0.7)` — не помогло. Два конфликтующих механизма (пин телепортирует, constraint двигает обратно).

### 4. Камера: `fitToHoles()` сбрасывает настройки
`fitToHoles()` вызывается из `drawableSizeWillChange` и перезаписывает `tiltAngle` и `rotationAngle` на дефолт. Из-за этого любые camera overrides для rescue mode молча исчезали при resize. Потратил кучу итераций не понимая почему камера не двигается.

### 5. Floor collision в 3+ местах
Искал floor collision в одном месте, патчил, а верёвки всё равно прижимались к Z=0. Оказалось floor collision дублируется в: constraint solver, board friction, bend solver. Патчить точечно — ненадёжно.

### 6. Верёвка с segmentLength=0
Инициализировал свободную верёвку с обоими концами в одной дырке (для удобства). Результат — segmentLength ≈ 0, все частицы в одной точке, верёвка не может расправиться после unpin.

## Инсайты (проверено, точно работает)

### 1. Level routing через levelId ranges работает
`levelId >= 4001` → rescue mode. Но порядок if/else важен — ставить ПЕРЕД `>= 3001` (braid), иначе 4001 попадает в braid.

### 2. `platformFragment` шейдер работает
Простой Lambert без wood texture (boardFragment требует 3D volume texture которой нет без boards). Создал отдельный `platformPipeline` с `boardVertex` + `platformFragment` — рендерит нормально.

### 3. Отключение table рендеринга даёт чёрный фон
`if !isRescueMode { draw table }` — работает, но без замены на что-то осмысленное выглядит как баг, а не фича.

### 4. Idle sleep нужно отключать для rescue
Физика замерзает через 3 сек без input (`isSleeping = true`). Для rescue это критично — платформа должна качаться от ветра постоянно.

### 5. Mesh платформы из 4 точек работает
`buildPlatformBox()` — 4 угла + thickness → top/bottom/4 sides с нормалями. Обновляется каждый кадр из corner positions. Рендерится через platformPipeline.
