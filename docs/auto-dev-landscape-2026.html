Автоматическая разработка: обзор рынка

Апрель 2026

1. CLI-агенты для автономной разработки

ИнструментФакты
Claude Code
Anthropic, закрытый		 SWE-bench Verified: 80.9% — лучший результат среди всех агентов. Нативные Agent Teams (параллельные субагенты). Headless-режим (claude -p) для автоматизации. Hooks для детерминистического enforcement правил.

Из отзывов: CLAUDE.md соблюдается примерно на 70% — это advisory, не enforcement. Один разработчик написал 200 строк правил, Claude проигнорировал все. Механические правила рекомендуют выносить в hooks. Без human review — 33% успешности на сложных задачах.
dev.to/minatoplanb, anthropic.com/research/measuring-agent-autonomy
Codex CLI
OpenAI, 75k stars, Rust		 Full-auto режим с kernel-level sandboxing (Seatbelt/Landlock). Облачное выполнение. Заявляется 4x эффективнее по токенам.

Из отзывов: слабее Claude по reasoning. Хорош для batch-задач в sandbox.
Devin
Cognition, закрытый, $20/мес + $2.25/ACU		 Единственный полностью асинхронный агент: получает задачу из Jira/Slack, сам пишет код, запускает тесты, открывает PR. Встроенный браузер, shell, редактор в sandbox.

Из отзывов: Answer.AI (Jeremy Howard) тестировали месяц на 20 задачах: 3 успеха, 14 провалов, 3 неопределённых. На рутине (миграции, lint-фиксы, юнит-тесты) работает. На сложных задачах уходит в тупик на дни вместо того чтобы остановиться. ~$9/час, непредсказуемый расход.
answer.ai/posts/2025-01-08-devin, news.ycombinator.com/item?id=42743697
OpenHands
All-Hands-AI, 71k stars, Python, MIT		 Open-source альтернатива Devin. Sandbox с браузером и терминалом — может исследовать веб перед кодом. Series A $18.8M. Model-agnostic.

Из отзывов: SWE-bench 53% (vs Claude Code 80.9%). Залипание в циклах — хорошо задокументированная проблема (issues #5480, #6357). Senior-lead из Германии: «не убеждён что экономит время». На чётких задачах (фикс бага) — работает с первой попытки. На открытых — требует надзора. Стоимость PR ~$3.
medium.com/@mchechulin, github.com/OpenHands/OpenHands/issues/5480

3. Методологии и паттерны

ПодходФакты
Spec-Driven Development
GitHub Spec Kit, 88k stars		 Четыре фазы: specify → plan → tasks → implement. 30+ интеграций с агентами.

Из отзывов: Scott Logic провели практический тест: 33 минуты и 2577 строк markdown для генерации 689 строк кода. Тот же результат итеративным промптингом — 8 минут. Статья «SDD Is Waterfall in Markdown» (Medium) описывает повторение ошибки аутсорсинга. Консенсус: окупается на крупных greenfield-проектах, для мелких задач — overhead.
blog.scottlogic.com, medium.com/@iamalvisng
Spec-Kitty
1k stars, Python, MIT		 Расширение подхода Spec Kit: CLI + Kanban-дашборд + swim-lane worktrees + auto-merge. FSM с 9 состояниями для каждого work package. 14 агентов из коробки. Среди исследованных проектов — единственный с реальным community (44 контрибьютора, 160 issues, упоминания на HN).
Ralph Loop
Addy Osmani, O'Reilly		 Атомарная задача → implement → validate → commit → reset context. Контекст сбрасывается каждую итерацию — меньше галлюцинаций. Stop hook блокирует завершение пока тесты не зелёные. Рекомендован как основной паттерн для автономной работы.
addyosmani.com/blog/code-agent-orchestra
Hooks > CLAUDE.md
Сообщество Claude Code		 CLAUDE.md — для контекста проекта. Механические правила (запускать тесты, не пушить в main, lint) — в hooks. Hooks — shell-скрипты, выполняются детерминистически вне модели.
code.claude.com/docs/en/hooks

4. Экспертные выводы (Addy Osmani, O'Reilly CodeCon 2026)

Работает

  • 3–5 агентов — sweet spot; больше не успеваешь ревьюить
  • Выделенный @reviewer (Opus, read-only) на каждые 3–4 builder'а
  • Plan approval перед кодом — дешевле починить план, чем код
  • AGENTS.md писать руками — AI-сгенерированные на 3% хуже, на 20% дороже по токенам (ETH Zurich)
  • Git worktrees для изоляции каждого агента
  • Multi-model routing: планирование на дешёвой модели, реализация на Opus/Sonnet

Не работает

  • Больше агентов чем можешь ревьюить — «ошибки компаундятся быстрее чем ловишь»
  • Два агента в одном файле — конфликты убивают скорость
  • Агенты без loop guardrails — бесконечный повтор одной ошибки
  • AI-сгенерированный AGENTS.md — нулевой или отрицательный эффект

Инструменты для аудита

  • Codex Web — цитаты из терминальных логов на каждую задачу
  • Conductor — diff-first review UI
  • Gastown — иммутабельные git-backed записи каждого решения, SQL-запрашиваемые

5. Итог

Готового инструмента для goal-driven автономной разработки (исследование домена → критерии приёмки → реализация → тестирование → документация trade-offs) не существует. Ни один из исследованных проектов не реализует этот цикл.

Кирпичи для построения своего решения: Claude Code (headless claude -p, top-1 по бенчмаркам), hooks (детерминистический enforcement), Ralph Loop (атомарные задачи + верификация), Linear MCP через rmcp (статусы, коммуникация с человеком).
